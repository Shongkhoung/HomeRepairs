🏠 HomeRepairs App

The HomeRepairs App is an Android application that helps users easily find, book, and manage home repair services such as plumbing, electrical work, and maintenance.
It includes user authentication, service listings, and real-time booking management.

🚀 Features

🔐 User Authentication — Sign up, sign in, forgot password (with Firebase Authentication)

🏘️ Add & Manage Properties — Users can add details about their homes

🧑‍🔧 Browse Services — View available repair services

📱 Responsive UI — Built with Material Design and Lottie animations

🔔 Email Verification and OTP Verification

💾 Firebase Integration — Store and retrieve data securely


🛠️ Tech Stack

- Language: Kotlin
- Framework: Android Studio
- Backend: Firebase Authentication & Firestore
- Animations: Lottie
- Tools: Git, Gradle

Setup Instructions

+ Clone the repository
git clone https://github.com/yourusername/HomeRepairs.git

- Open in Android Studio
- Connect Firebase
- Go to Tools → Firebase in Android Studio
- Connect your app and enable Authentication
- Build and Run the project on an emulator or real device.
